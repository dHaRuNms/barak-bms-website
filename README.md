# Barak Microelectronics — Full-Stack Battery Management System & Deep-Tech Web Platform

> **Powering Next-Generation Mobility & Intelligent Hardware Systems**  
> Pioneering high-reliability Battery Management Systems (BMS), digital twin battery simulation, Clara AI diagnostic copilot, open EDA tools, and EV fleet operations.

---

## ⚡ Overview & Aesthetic Architecture

Built with an **Anti-Slop, deep-tech engineering standard** inspired by **Prime Intellect** (absolute black `#050505`, ultra-thin geometric borders `border-white/10`, stark micro-typography) and **Lightship RV** (cinematic, scrubbed scroll animations where sections physically assemble and disassemble seamlessly tied to user scrollbar).

### Core Technological Pillars:
1. **Hardware Solutions**: Automotive-grade, high-reliability Battery Management Systems with ±1.0mV ADC precision, dual active/passive cell balancing, and sub-15µs hardware interrupt protection.
2. **Software & Simulation**: Open-source EDA PCB design tools and electrochemical digital twin simulator for rapid Hardware-In-The-Loop (HIL) algorithm validation.
3. **Fleet & AI Operations**: Clara Bot AI technical diagnostic assistant, real-time EV auto-rickshaw fleet dispatch, and live battery health telemetry.

---

## 🛠️ Technology Stack

- **Framework**: [React 18](https://react.dev/) + [Vite](https://vitejs.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) with custom Prime Intellect absolute black tokens and cursor-tracking spotlight effects
- **Animation**: [GSAP](https://greensock.com/) + [ScrollTrigger](https://greensock.com/scrolltrigger/) with `scrub: 1` physics
- **3D Silicon Mesh**: [Three.js](https://threejs.org/) + [@react-three/fiber](https://docs.pmnd.rs/react-three-fiber/)
- **Icons**: [Lucide React](https://lucide.dev/)

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Local Development Server
```bash
npm run dev
```
Open `http://localhost:5173` in your browser.

### 3. Build for Production
```bash
npm run build
```
